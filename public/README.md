# Carpeta de Archivos Públicos

## Logo de Empresa

Coloque su archivo `logo.png` en esta carpeta para que aparezca en la página de login.

### Especificaciones recomendadas:
- **Nombre del archivo:** `logo.png`
- **Formato:** PNG con fondo transparente
- **Dimensiones recomendadas:** 512x512 px o similar (cuadrado)
- **Tamaño máximo:** 500KB

El logo se mostrará automáticamente en la página de inicio de sesión con un tamaño de 128x128 píxeles (ajustable).

## Otros Archivos

Puede colocar otros archivos estáticos en esta carpeta como:
- Favicons
- Imágenes
- Archivos PDF
- etc.

Estos archivos serán accesibles desde la raíz del sitio web (ej: `/logo.png`).
